## Решения

- Суммы API — в копейках; конфиги и расчёты — в рублях, `Decimal`.
- `approval_likelihood` — эвристика, не вызов ML-модели.
- `config_version` возвращается в ответе; персистентности рекомендаций нет.
- Недоступные в кабинете продукты остаются в выдаче, но без кнопки оформления.
- Сумма и срок при переносе в форму ограничиваются каталогом кабинета.
- Сотрудник получает `staff_trace` только при явном `company_id`.

## Риски и следующие шаги

- Пороговые значения и ставки в `products.yaml` стоит сверить с продуктовой
  командой перед пилотом.
- Для продакшена нужно решить, откуда брать ЕГРЮЛ/БКИ/финансовые данные вместо
  демо-профилей.
- После появления PostgreSQL в окружении прогнать интеграционные API-тесты и
  e2e-сценарии, включая панель подбора.
