# Умный кредитный кабинет

Проект для хакатона Альфа-Банка 2026: веб-кабинет для подачи и рассмотрения кредитных заявок малого бизнеса.

## Основной сценарий

Предприниматель выбирает финансирование, заполняет заявку, прикладывает документы и отслеживает рассмотрение. При необходимости он дополняет сведения или принимает предложенные условия.

Сотрудник банка изучает заявку, результаты проверок и оценку риска, запрашивает уточнения и принимает решение. История действий связывает оба кабинета.

Первые продукты — оборотный кредит и кредит на оборудование.

## Планируемый стек

- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Данные: PostgreSQL
- Frontend: React, TypeScript
- ML: табличный скоринг и объяснение факторов риска
- LLM: помощник для работы с заявкой и справочником
- Запуск: Docker Compose

## Данные и проверки

Для демонстрации используются синтетические компании, документы и финансовые сведения. Проверки реестра, ФНС и БКИ воспроизводятся симуляторами. Условия кредитования демонстрационные.

Оценка риска отделена от правил кредитного решения.

## Запуск

Приложение находится на этапе проектирования. Инструкция воспроизводимого запуска через Docker будет добавлена вместе с первой работающей версией.
